# Tests

This folder contains test files for the backend and frontend applications. Tests ensure that the code is working as expected and help prevent regressions.

## Files

- `unit/`: Unit tests for individual functions and components.
- `integration/`: Integration tests for testing multiple components and functions together.
- `e2e/`: End-to-end tests for testing the entire application flow.

## Usage

Tests should be written to cover all critical functionality and edge cases in the application.
