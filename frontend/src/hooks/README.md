# Hooks

This folder contains custom React hooks for the frontend application. Hooks are functions that let you use state and other React features in functional components.

## Files

- `useAuth.ts`: Custom hook for authentication.
- `useFetch.ts`: Custom hook for fetching data.
- `useVideo.ts`: Custom hook for video-related operations.

## Usage

Hooks should be used to encapsulate logic that can be reused across multiple components.
