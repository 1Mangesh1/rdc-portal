# Documentation

This folder contains documentation for the project. Documentation includes guides, API references, and other resources to help developers understand and work with the project.

## Files

- `API.md`: API reference for the backend server.
- `design/`: Design documents and assets.
- `Postman Collection/`: Postman collections for testing the API.
- `requirements.md`: Project requirements and specifications.

## Usage

Documentation should be kept up to date and used to provide information and guidance to developers working on the project.
