# Design

This folder contains design documents and assets for the project. These documents include wireframes, mockups, and design guidelines.

## Files

- `wireframes/`: Wireframes for different pages and components.
- `mockups/`: High-fidelity mockups for the application.
- `guidelines.md`: Design guidelines and best practices.

## Usage

Design documents should be used to guide the development of the user interface and ensure consistency across the application.
